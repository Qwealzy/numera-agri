2. Prim Temerrüdü — ödemesiz kalanlar

Bildirim tebliğ tarihi dışarıdan verilir; ödemesiz sürenin bittiği an = tebliğ tarihi + poliçenin kendi grace_period_days değeri. Süre dolduğunda graceSweeper.js poliçeyi askıya alır — teminat durur, ancak poliçe sonlandırılmaz.

3. Yenileme Zincirleri

Bir yenileme yeni bir poliçe açar ve öncekine dokunmaz — ikisinin de aynı anda canlı olması normaldir, hata değildir. Aradaki gün farkı: 0 = kesintisiz, >0 = teminatsız boşluk, <0 = örtüşme. Sistem bunu denetlemez; burada yalnızca görünür kılınır.
